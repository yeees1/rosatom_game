# Атомные связи

Локальная веб-версия второго этапа «Атомные связи» по предоставленному документу. Интерфейс на русском, без регистрации и внешних сервисов. Иллюстрации SVG выполнены специально для игры; символ сообщества условный, а портрет Курчатова стилизованный.

## Запуск

Требуется Node.js. Установка пакетов не нужна.

```sh
git clone https://github.com/yeees1/rosatom_game.git
cd rosatom_game
npm start
```

Откройте http://127.0.0.1:4173. Для остановки сервера нажмите Ctrl+C в терминале. Проверка логики: `npm test`.

## Правила

16 карточек / 8 смысловых пар / 4 минуты. Простой режим: 12 карточек / 6 пар / 4 минуты. Количество участников и время игры в целых минутах вводятся вручную в настройках перед стартом. Участники передают управление одним экраном после каждого хода. Все карточки в начале лежат рубашкой вверх. Каждый ход состоит из последовательного открытия двух карточек. Неверная пара переворачивается через 1,1 секунды и остаётся на месте; правильная появляется в зоне ответа. Разговоры и письменные подсказки запрещены, жесты разрешены. Для каждой найденной связи доступно объяснение.

Буква шифра в исходном документе не задана: значение «А» можно поменять в настройках до начала игры. Настройки сохраняются в браузере. Правила и объяснения не останавливают таймер. Победа раскрывает второй фрагмент шифра; окончание времени позволяет изучить найденные пары и повторить игру.

Игра работает без интернета. Шрифт Golos Text загружается из Google Fonts при наличии сети, иначе используется системный шрифт. Сервер слушает только локальный адрес 127.0.0.1. Онлайн-мультиплеер и сложный режим с 10 парами не включены: дополнительные пары в исходном документе не заданы.
